# Beacon Finance Opportunities — QA report

Date: 2026-09-26  
Target: `http://127.0.0.1:5173/`

## Outcome

The discovery, detail, saved, comparison, search, filter, and responsive flows passed the final product-quality check. The swipe experience fits a single viewport at 1280×720 and 390×844 while retaining the core decision information and actions.

## Verified flows

- Save advances the deck and updates the saved count.
- Undo restores the prior card, saved state, comparison state, and progress.
- Compare advances the deck and exposes a direct shortlist entry point.
- The deck stops after all matching opportunities are reviewed and offers a reset.
- Detail routing preserves deck position and browser back behavior.
- Direct application and original-source links use organization URLs.
- Search supports titles, organizations, categories, locations, format aliases, eligibility, and commitment; empty results have recovery actions.
- Filters compose across all specified groups and show a truthful live result count.
- Saved items sort correctly and persist status and personal notes.
- Comparison adapts from one to four opportunities without column drift.
- Desktop 1280×720 and mobile 390×844 layouts were visually inspected.
- Mobile navigation, profile menu, filter drawer, and search dialog were exercised.
- Browser console reported no errors or warnings during the final run.
- `npm run build` passes.
